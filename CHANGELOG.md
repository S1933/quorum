# Changelog

## [0.1.0] — 2026-06-13

### Added
- Multi-reviewer code review with configurable pipelines
- Provider support: OpenRouter, Ollama, Claude Code, Codex CLI, Cursor Agent, Gemini CLI, Kilo Code, OpenCode
- Consensus strategies: overlap, majority, severity-aware, semantic-v2
- Plan review command for reviewing implementation plans
- Interactive Q&A mode for multi-reviewer feedback
- Dashboard TUI for monitoring review pipelines
- Biome linter/formatter integration
- Dockerfile (oven/bun:1.3-alpine)
- Architecture decision records (docs/adr/)
